Built for Speed, Versatility & Privacy

Designed from the ground up to give you complete freedom over your files without compromises or third-party cloud lock-in.

☁

Multi-Cloud & Network Storage

Connect and browse all your remote drives and servers directly alongside local storage. Stream remote videos and audio on the fly without waiting for full downloads.

  • Google Drive: OAuth2 authentication & Google Drive API v3
  • Microsoft OneDrive: Microsoft Graph API & Entra ID
  • Nextcloud / ownCloud: WebDAV & QR Code instant setup
  • SMB / Windows Shares: CIFS/SMB2/SMB3 LAN protocol
  • WebDAV & FTP: Generic NAS, Synology & server connections
▶

Universal Media Player Engine

Hardware-accelerated playback for videos, audio tracks, comic books, digital documents, and image galleries with smooth gestures and quick drawer navigation.

  • Video Player: MKV, MP4, WebM, AVI, MOV with multi-audio, subtitle tracks, speed control, ±5s seek & orientation lock
  • Audio with Waveforms: Visual waveform preview, scrub seeking, embedded metadata tags (artist, album, bitrate)
  • Comics & Manga: CBZ, CBR, ZIP archives with smooth page-curl transitions, pinch zoom & tap zones
  • Documents & eBooks: High-definition PDF rendering & EPUB readers
  • Images & GIFs: Ultra-fast hardware decoding, animated GIFs, deep pinch-to-zoom
🔒

100% Privacy-First Architecture

Lenta is client-only. It communicates directly and securely from your device to your storage providers with zero middleman proxy servers.

  • Zero analytics, zero tracking, and no advertising SDKs
  • Credentials & OAuth tokens stored securely on your local device
  • Strict compliance with Google API & Microsoft Entra Limited Use policies
  • Open-source codebase for full transparency and security auditability
⚡

Intelligent Thumbnail Engine

Fast visual file browsing powered by background extraction and multi-tier memory and disk caching.

  • Video Frame Sampling: Extracts clear representative frames at optimal timestamps
  • Comic Cover Extractor: Instantly unpacks and renders CBZ/CBR cover artwork
  • LRU Memory & Disk Cache: Low memory footprint with instant cache reuse
  • Built-in cache management settings to purge or limit disk storage usage
🎨

Material Design 3

Clean, modern UI designed according to the latest Android design standards with comprehensive theming.

  • Full Light and Dark system theme adaptation
  • Collapsible media playlist side-drawer for instant file switching
  • Interactive indicator badges and responsive grid/list layouts
  • Smooth animations and edge-to-edge layout design
🔄

In-App Updates

Seamless version checking and direct installation built directly into the app.

  • GitHub Releases Integration: Automatically detects new versions with rich release changelogs
  • One-Tap Download: Fast in-app background download for new APK releases
  • Direct Installation: Seamless package installer prompt to update without leaving the app

Technical Specifications

Engineered with modern Android development best practices and robust architectural components.

Platform & OS

Android 13+ (API Level 33+) for optimal performance, modern permissions, and hardware acceleration.

Core Stack

Kotlin 2.0, MVVM Architecture, Kotlin Coroutines, StateFlow, and Jetpack AndroidX components.

Media Stack

ExoPlayer / Media3 for high-fidelity audio/video, Coil for image rendering, and custom vector decoders.

Open Source

Licensed under CC BY-NC-SA 4.0. Completely free, customizable, and developer-friendly.

Privacy Transparency & Developer Integration

Lenta respects user privacy and complies with all official developer security standards, including Google Cloud OAuth Limited Use and Microsoft Entra verified publisher requirements. Ready for custom developer credentials and enterprise deployments.
